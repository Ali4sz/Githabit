Anatomy

From sketch to symbol.

The napkin drawing had three circles on a line and a check in the middle. That's the whole product: days on a branch, and the quiet satisfaction of closing one.

01The branch

A single horizontal line reads as both a timeline and a git branch. Every day is a node; every habit is a commit to yourself.

02Open nodes

Small hollow circles are days still open — yesterday and tomorrow. They stay quiet, so the icon never nags.

03Today, checked

The larger center node closes with a check. One bold green moment in the whole mark: the habit you kept today.

04The container

A 22%-radius square on GitHub's canvas dark, with a hairline border and generous clearspace. Legible from 512 px down to 16.

Color

The GitHub palette.

Every value is lifted from GitHub's dark-mode system — contribution greens carry the mark, Primer neutrals carry the surface. Click any chip to copy its hex.

Light variant swaps Canvas → #FFFFFF and Done → #1F883D, GitHub's light-mode green.
